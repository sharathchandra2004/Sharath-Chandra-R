# Sharath Chandra R Portfolio

A two-mode personal portfolio: a professional view for engineering work and a creative view for writing, photography, cinema, and workshops.

## Development

```bash
npm install
npm run dev
```

Run `npm run storybook` to inspect the reusable component library. Content is maintained in `src/content`; the component architecture is documented in [PORTFOLIO_PLAN.md](./PORTFOLIO_PLAN.md).
